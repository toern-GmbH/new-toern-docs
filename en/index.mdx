Great to have you on board. toern automates your return process: your customers register returns in the **return portal**, and you manage them in the **toern dashboard**. With **integrations**, you connect toern to your shop, your fulfillment, your shipping carriers, and other tools.

Find everything you need to set up and use toern.

## Your onboarding

Follow these steps to make your start as smooth as possible.

<Steps>
  <Step title="Connect your Shopify shop">
    Install the [toern Shopify app](/en/shopify/app) and set up the [shop integration](/en/getting-started/shopify-integration).
  </Step>
  <Step title="Set up fulfillment">
    Connect your fulfillment to toern. Learn more in [Fulfillment integration](/en/fulfillment/fulfillment-integration).
  </Step>
  <Step title="Set up shipping">
    Set up your shipping carrier, e.g. [DHL](/en/carriers/dhl), [DPD](/en/carriers/dpd), [GLS](/en/carriers/gls), or [PostNord](/en/carriers/postnord). Learn more in [Return methods](/en/returns/return-methods).
  </Step>
  <Step title="Set up return portal logic">
    Configure the most important settings. Learn more in [Set up return portal logic](/en/getting-started/return-portal-logic) and [Brand your portal](/en/getting-started/brand-your-portal).
  </Step>
  <Step title="Add users">
    Add more users for your brand. Learn more in [User management](/en/dashboard/user-management).
  </Step>
  <Step title="Set up integrations">
    Set up more integrations, e.g. Klaviyo or Zendesk.
  </Step>
  <Step title="Test the return process">
    Test the entire return process before you go live.
  </Step>
  <Step title="Go live">
    Add the link to your return portal to your shop.
  </Step>
</Steps>

## Test the return process

Test the return process end to end before you add the link to your shop and your customers can use it. Below we describe a basic test. Ideally, you test several orders and all known edge cases.

### 1. Create a test order

First, create a test order in Shopify. Ideally, choose 2–3 items. This gives you a choice when registering the return, and you can test different things per item, e.g. gift card or exchange.

<Info>
  The order must be **fulfilled** before a return can be registered. Customer data must also be on file. To test refunds, use a real payment method or the test method **Bogus**.
</Info>

### 2. Register a return

Now register a return. There are two ways:

- Via your return portal with order number and email address. Learn more in [Return portal](/en/returns/return-portal).
- Manually via **Create new Return** on the **Manage Returns** page. Learn more in [Manage Returns](/en/dashboard/manage-returns).

### 3. Run through the return in the dashboard

Registered returns appear under **Manage Returns** with the status **registered**. Select the return and go through the entire return timeline. You need to simulate the **Received** status, since nothing is actually shipped.

Try out all functions, e.g. classifying items, creating a new label, processing manual refunds, or issuing a gift card.

### Check your return policy

Before adding the link to your shop, check your return policy. It should cover all information on return periods and return fees for each country. If you don't have a policy yet, use our integration templates as a starting point. You'll find them in [Return portal](/en/returns/return-portal).

## Go live

All tested? Then add the link to your return portal to your shop. From this moment on you're **live** and your customers can register returns via toern.

```text
https://app.re-toern.de/<name>
```

You create and copy the link under **Settings → Shop Integration → Return Portal Link**. Learn more in [Connect your Shopify shop](/en/getting-started/shopify-integration#return-portal-link).

<Warning>
  As soon as the link is live in your shop, please let [support@re-toern.de](mailto:support@re-toern.de) know.
</Warning>

<Tip>
  Still have questions? Contact our customer support at any time at [support@re-toern.de](mailto:support@re-toern.de). You'll also find answers to common questions in the [FAQ](/en/faq) and the [Glossary](/en/glossary).
</Tip>
