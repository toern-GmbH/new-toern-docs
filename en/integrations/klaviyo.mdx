title: "Klaviyo"

---

With the **Klaviyo integration**, toern automatically sends events to Klaviyo as soon as certain steps happen in the return process. You can use these events in Klaviyo to trigger flows, personalize your customer communication or build segments. For example, you can keep your customers updated on the status of their return.

## Setup

### Create an API key in Klaviyo

You need a **private API key** with the scopes **Read - Accounts** and **Full Access - Events**.

1. Log in to Klaviyo.
2. Click your user profile at the bottom left of the navigation and select **Settings**.
3. Go to **API keys** and create a new private API key.
4. Name the key "toern Integration".
5. In the scopes table, select **Read - Accounts** and **Full Access - Events**.
6. Click **Create** in the top right corner.
7. Reveal the new private key and copy it.

### Add the key in toern

1. Open your toern dashboard.
2. Go to [Settings → Third Party Services → Klaviyo](https://www.admin.re-toern.de/settings/third-party/klaviyo).
3. Paste the private key from Klaviyo and save it.

<Frame><img src="/images/docs/Klaviyo/KlaviyoNew01.png" alt="Klaviyo private key in toern" /></Frame>

That's all you need to set up in toern for the connection to work.

- **Verify SetUp**: Checks the connection to Klaviyo. If the key has the **Read - Accounts** scope, the check tells you whether toern can send requests to Klaviyo.
- **Create Test Events**: Sends test events from toern to your Klaviyo account. This helps you while building your flows, for example to send test emails. Afterwards, all events toern sends to Klaviyo are visible in Klaviyo.

### Select Klaviyo as email service

To have Klaviyo handle your transactional emails, select Klaviyo as your email service.

1. Go to [Settings → Return](/en/returns/return-settings).
2. Under **Notifications during Return Process - enable additional customer notifications**, select Klaviyo as the email service.

<Frame><img src="/images/docs/Klaviyo/Klaviyo06.png" alt="Select Klaviyo as email service" /></Frame>

From now on, email events are sent directly to Klaviyo.

<Warning>
  Once Klaviyo is selected as the service, toern no longer sends transactional emails to customers during the return process.
</Warning>

## Events in Klaviyo

### Overview of all events

| Event | Description | When it's triggered |
|---|---|---|
| `ReturnRegisteredLabel` | A return was registered and a shipping label was created. | Right after a successful registration in the return portal with label creation. |
| `ReturnRegisteredWithoutLabel` | A return was registered without a shipping label (e.g. the customer ships the parcel themselves). | After a return is registered without label creation. Only if no label should be generated and the customer ships on their own. |
| `ReturnRegisteredLabelFailed` | The shipping label could not be created. | If the label service is unavailable or the label could not be generated. Only if `ReturnRegisteredLabel` fails. |
| `ReturnRegistered` | A return was recorded in the system through the return portal. | General start signal for the return process. The label process is not finished at this point. |
| `ReturnInTransit` | The return is on its way to the warehouse. | As soon as tracking shows that the parcel is on its way. |
| `ReturnReceived` | The return has arrived at the warehouse. | After the physical goods receipt in the warehouse. |
| `ReturnInspected` | The goods have been inspected. | After the quality check in the warehouse is done. |
| `ReturnRefunded` | The purchase amount was refunded. | As soon as the refund has been made in the system. |
| `ReturnCompleted` | The entire return process is complete. | After final confirmation that the process is fully complete. |
| `ReturnCanceled` | The return was canceled or aborted. | When the customer or the system cancels the process. |
| `ReturnForgotOrderNumber` | The customer asks for their past order numbers. | When requested in the return portal. |
| `WiderrufReceivedAcknowledgement` | Confirmation that a withdrawal was received. | When a withdrawal has been received. |
| `WiderrufOrderCanceled` | Confirmation that the order was canceled. | When fulfillment hasn't happened yet and toern was able to cancel the order directly. |

<Warning>
  If you send the refund email (`ReturnRefunded`) through Klaviyo, also check your Shopify notifications. Otherwise your customers may receive the email twice.
</Warning>

### Event data fields

All events contain structured data you can use for email content or segments.

<Warning>
  Always put `event.` in front of the data field. For the brand name, use `{{event.brandName}}` instead of `{{brandName}}`.
</Warning>

In the table, **status events** means: `ReturnRegistered`, `ReturnInTransit`, `ReturnReceived`, `ReturnInspected`, `ReturnRefunded`, `ReturnCompleted`, `ReturnCanceled`.

## Limitations

- Klaviyo and the [toern email editor](/en/branding/email-templates) are alternatives. With Klaviyo, you manage content and sending in Klaviyo. With the toern service, you customize the templates in the email editor.
- The events are defined by toern.
- The included data fields are described on this page.
- There are currently no templates for the flows of the individual events.
