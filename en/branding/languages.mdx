Offer your customers the return portal in their language. You define which languages are available in the portal and maintain your email templates separately for each language.

## Return Portal Languages

Under **Settings → Branding → Return Portal Languages**, you define which languages are available to your customers in the return portal.

- **German and English are always active** and can't be disabled.
- You can optionally enable additional languages such as **Finnish**.

### Enable a language

1. Open **Settings → Branding**.
2. Scroll to **Return Portal Languages**.
3. Enable or disable the language using the toggle in the **Status** column.

In the return portal, your customers can then switch between the enabled languages using a language dropdown.

<Note>
  This setting affects the texts of the return portal. You manage return reasons separately under [Return reasons](/en/returns/return-reasons). If a customer selects Finnish, for example, the return reasons are automatically shown in English.
</Note>

## Languages in email templates

You customize your email templates in the email editor separately for each language available to your brand. You always edit a combination of **email event** and **language**.

1. Open the email editor and select the template.
2. Select the **language flag** in the top right.
3. Edit and save the template.

Keep in mind:

- A change only applies to the currently selected language. The German and English templates are independent of each other.
- If no standard template exists for a language, it's shown as **Empty**. You can then create the content from scratch. Check the subject, variables, and test email especially carefully.

<Warning>
  Save before switching language or template. Unsaved changes are discarded when you switch.
</Warning>

## Limitations

- Besides German and English, only Finnish is currently available as an additional language for the return portal.
- With Finnish, return reasons are automatically shown in English.
