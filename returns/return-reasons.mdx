Mit Retourengründen erfährst du, warum deine Kunden Artikel zurückschicken. Die Gründe fließen in deine Auswertung ein, sowohl pro Artikel als auch produktübergreifend. So erkennst du Probleme mit Passform, Qualität oder Beschreibung schneller.

## So funktionieren Retourengründe im Portal

Wenn deine Kunden einen Artikel für die Retoure auswählen, müssen sie im ersten Unterschritt genau einen der vordefinierten Gründe auswählen. Erst dann geht es im Prozess weiter.

<Frame><img src="/images/docs/Retourenportal---Standardprozess/Returnreasons.png" alt="Auswahl der Retourengründe im Retourenprozess" width="300" /></Frame>

Den gewählten Grund findest du im Dashboard in der einzelnen Retoure und in der Auswertung bei den Retourendetails. Wie der gesamte Ablauf für deine Kunden aussieht, erfährst du unter [Retourenportal](/returns/return-portal).

## Collections

Retourengründe verwaltest du in sogenannten **Collections**. Eine Collection enthält beliebig viele Gründe in einer festen Reihenfolge. Du kannst Collections bestimmten Produkten zuordnen. Deine Kunden sehen im Portal dann die Gründe der passenden Collection.

### Default Collection

Die **Default Collection** wird bei allen Produkten angezeigt, denen keine andere Collection zugewiesen ist. toern stellt eine Default Collection für **Fashion** bereit. Sie ist ausgewählt, bis du eine eigene Collection erstellst und auswählst.

<Frame><img src="/images/docs/Settings/ReturnReasonsNew01.png" alt="Default Collection in den Return-Reasons-Settings" /></Frame>

Die Default Collections von toern kannst du nicht bearbeiten oder löschen. Du kannst sie dir nur ansehen.

## Einrichtung

### Collection erstellen

1. Klicke auf **Create Collection**. Es öffnet sich eine neue Seite für deine Collection.
2. Gib einen Namen für die Collection ein.
3. Klicke auf **Update**, um zu speichern.

<Frame><img src="/images/docs/Settings/ReturnReasonsNew03.png" alt="Namen für eine neue Collection festlegen" /></Frame>

### Gründe hinzufügen

1. Klicke auf **Add reason**. Es erscheint eine neue Kachel mit Textfeldern für eine deutsche und eine englische Beschreibung.
2. Fülle beide Beschreibungen aus.
3. Optional: Wähle unter **Shopify reason** einen Shopify-Grund aus. Auf diesen Grund wird dein Retourengrund in Shopify gemappt.
4. Passe die Reihenfolge mit den **Pfeiltasten** auf den Kacheln an.
5. Entferne einen Grund über das **Mülltonnen-Symbol**.

### Collection freischalten

Mit **Release Collection** schaltest du die Collection für den Retourenprozess frei. Dabei werden das Mapping und alle weiteren Zuordnungen festgeschrieben.

<Warning>
  Nach dem Release kannst du die Reihenfolge nicht mehr ändern und keine neuen Gründe hinzufügen. Willst du eine geänderte Collection verwenden, musst du eine neue Collection anlegen.
</Warning>

### Collection Produkttypen oder Tags zuordnen

Du kannst eine Collection Produkttypen oder Tags aus Shopify zuordnen. So zeigst du für unterschiedliche Produkte unterschiedliche Gründe an. Mützen brauchen zum Beispiel andere Gründe als Bikinis.

Hinterlege dafür den **exakten** Produkttyp oder Tag aus Shopify.

<Frame><img src="/images/docs/Settings/ReturnReasonsNew02.png" alt="Collections Tags und Produkttypen zuordnen" /></Frame>

## Einschränkungen

<Warning>
  - Es gibt genau eine Default Collection. Willst du für andere Artikel andere Gründe anzeigen, erstellst du weitere Collections und ordnest sie über Produkttypen oder Tags zu.
  - Sobald eine Collection über **Release** freigeschaltet wurde, kannst du keine neuen Gründe mehr hinzufügen.
</Warning>
