---

Sets (auch Bundles genannt) bestehen aus mehreren Artikeln, die gemeinsam verkauft werden. Im Retourenprozess werden sie je nach Shopify-App als Einheit oder als Einzelteile behandelt.

## Sets über Shopify-Bundle-Apps

toern kann Sets aktuell nur automatisiert verarbeiten, wenn du eine offizielle Bundle-App in Shopify nutzt. Die App hinterlegt die Einzelartikel eines Sets in der Bestellung. So können deine Kunden die Einzelartikel im Retourenportal auswählen.

## Klärfall bei Set-Artikeln

Kann toern ein Set nicht automatisiert verarbeiten, entsteht der Klärfall **Retoure enthält einen Set-Artikel** (Return contains a set item). Die Retoure wird angehalten, damit du sie von Hand prüfen kannst. Prüfe die Retoure im toern Dashboard unter [Retouren verwalten](/dashboard/manage-returns) und klicke danach in der Klärfall-Karte auf **Erneut versuchen**. Der Set-Artikel gilt dann als geprüft und die Verarbeitung läuft weiter (siehe [Klärfälle](/returns/clarifications)).

## Einschränkungen

<Warning>
  Ohne Bundle-App kann toern Sets nicht automatisieren. Die Zugehörigkeit der Einzelartikel zu einem Set wird in der Retourendetailansicht nicht angezeigt und nicht gesondert behandelt.
</Warning>
